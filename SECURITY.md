# Security policy

## Private disclosure

Use the repository's [Security tab](https://github.com/howard1984/siworld/security)
to submit a private vulnerability report when private reporting is available.
Keep vulnerability details and reproductions out of public issues and pull requests.

Include the affected release or revision, the component, prerequisites,
observed impact, and a minimal reproduction using synthetic data. Exclude
wallet material, credentials, nonpublic endpoints, and personal data.
Disclose a reporter's identity only with their permission.

## Security model

The [security model](docs/security/security-model.md) documents proof
assumptions, observer visibility, and the boundaries of full-node,
light-wallet, and checkpoint verification. Use the network and software
listed in the applicable release manifest when reporting observed behavior.
