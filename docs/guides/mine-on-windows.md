# Mine on Windows

**Public releases**

Genesis ID and installation packages: Published at network launch.

Use the Windows package only on a platform listed in its release manifest.
Verify the archive checksum and keep the bundled executable and worker
directory together. Run the package's `--help` and `--check-hardware`
commands before selecting the verified network bundle. The launcher checks
local hardware before starting the worker. Keep wallet recovery material
offline and request a clean stop before moving the data directory.
